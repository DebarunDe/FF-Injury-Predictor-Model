# FF-Injury-Predictor-Model
The Injury Predictor model for the FF project to showcase CI/CT/CD pipelines/skills

This repo is scaffolded with minimal starter files. See `FF_Injury_Predictor_Model_Design.yaml` for the full design and runtime commands.

Quickstart (local):

1. Copy `.env.example` to `.env` and set `API_TOKEN`.
2. Install dependencies: `pip install -r requirements.txt` (use Python 3.11).
3. Run dev server: `python -m src.serve.app` (listens on port 7860).
